# 本地产物与证据

生成文件由 Git 忽略，根目录 target 仅存日常编译输出。

| 路径 | 用途 |
| --- | --- |
| validation/<专题>/<run-id>/ | 合成输入、日志、采样、截图与测量结果；新运行不覆盖旧证据 |
| dist/<版本>/<目标>/ | 独立发布构建、装配快照、附件和哈希 |
| reviews/<日期-主题>/ | 审查快照、旧文档备份和重组核对结果 |
| work-notes/ | 本地任务流水记录；稳定结论回写设计 |

旧 validation/p0、p1、p2、p2-p3 目录可继续读取，不为文档整编迁移大体积证据。后续按测试专题命名，停止向 Git 添加阶段日记。2026-11-14 文档重组前的快照在 reviews/2026-11-14-redesign/before，暂存补丁保存在同级目录。

本地忽略目录不是共享归档。发布证据需随发行附件或持久存储保存并记录哈希/位置；原始敏感日志先脱敏。参见[开发工作流](../docs/development/workflow.md)与[发布管理](../docs/development/release.md)。
