# 现阶段功能规格

本文规定产品行为和缺省值。阶段关口见 [G-04](G-04-delivery-plan.md)。

## 1. 用户路径与默认行为

首次启动 → 检查配置与资源 → 有效角色待机 → 托盘与右键菜单可用 → 用户按需开启集成。启动不要求账号；不扫描个人会话，直到用户启用对应集成。首期一个实例、一个角色窗口，重复启动激活既有实例设置或提示已运行。

新安装默认：自移动开启、全屏自动隐藏开启、音效开启、任务气泡开启；自启、全窗口鼠标穿透和外部集成关闭。角色缩放为 50%–200%，气泡缩放为 50%–150%。用户可在配置文件设定尺寸和功能开关的启动值，也可在运行时通过对应设置调整并保存。无有效尺寸偏好时按 F-06 选定，回退基准为 256×256 DIP。配置覆盖和保存规则见 [G-05](G-05-contracts.md#配置分层)。素材包仅从本地读取。启动要求配置包或默认包可用。配置文件加载失败时由用户决定是否备份原件并以默认值覆盖。

托盘和角色右键共享同一命令模型：显示/隐藏、展开、动作预览、禁用自移动、桌宠大小、音效、全屏隐藏、鼠标穿透、设置、集成/会话、历史、退出。能力不支持的入口显示原因；菜单文本不声称已登录或已连接。

## 2. 普通桌宠需求

| ID | 触发与正常行为 | 边界/失败处理 | 验收阶段 |
| --- | --- | --- | --- |
| F-01 启动/退出 | 启动待机，托盘可退出；退出保存偏好并回收 worker/子进程 | 第二实例不重复创建；托盘创建失败时提供可见退出入口 | P1a/P2 |
| F-02 播放/预览 | 按素材时间戳循环待机；右键选择可用动作，结束返回基础状态 | 缺帧保留最后有效帧、超时回待机；无效动作禁用并给原因 | P1b/P2 |
| F-03 点击/拖拽 | 单击互动；双击查询额度（需能力）；越过系统拖动阈值进入拖拽，松手落地 | 双击抑制单击，拖拽后抑制点击；禁用集成时双击显示连接提示 | P2 |
| F-04 自移动 | 按动作移动时窗位移，结束冷却；关闭自移动仍可手动预览移动动作 | 不镜像不支持方向的素材；拖动即时中断；位置不瞬移 | P2 |
| F-05 吸边 | 手动靠近左右工作区边缘吸附，点击切换探头姿态，菜单展开 | 吸边暂停自主移动；双击额度不退出吸边；屏幕消失后恢复可见区域 | P2 |
| F-06 尺寸/多屏 | 首次启动优先按目标显示器的可视区物理尺寸比例确定默认大小；有效的配置尺寸优先；实时预览并保存手动尺寸 | 探测不可用时回退 256×256 DIP；支持负坐标、任务栏和混合 DPI；缩放后重新约束位置，设置窗保持原位 | P2 |
| F-07 可见性 | 手动隐藏与目标显示器前台全屏隐藏独立；托盘恢复 | 手动隐藏不因全屏退出而恢复；隐藏停动画/上传/移动，恢复不补跑位移 | P2 |
| F-08 音效/气泡 | 点击/结果音效可关闭；任务气泡可独立关闭；长内容打开详情 | 失败不播放成功音效；任务静音不影响主动互动/额度，气泡不抢焦点 | P2/P3 |
| F-09 偏好/平台 | 设置实时预览并按需保存、Windows 当前用户登录自启、全窗口穿透可由托盘撤销 | 自启失败展示错误；坏配置保留原文件并使用默认，不静默覆盖 | P2 |

首期自主移动限制在当前显示器工作区；用户拖拽可换屏。吸边设计值为距左右边缘 16 DIP 以内松手触发，展开退回可见区。动作目录使用稳定 ID，逐动作核对画布变换、方向及移动时窗。

P2-01 使用 250 ms 单击判定窗口、750 ms 缺页等待、15 s 自移动等待和 10 s 冷却。每次路线最多 144 DIP，至少有 16 DIP 可用空间。参数及复测见 [P2-01 实施记录](stages/p2/P2-01-core-behavior.md)。旧版取值见 [P0 行为基线](archive/p0/R-01-p0-baseline.md#p0-02--旧行为)。动作未声明适用方向或移动时窗时，仍可作为适用的原地动作预览，自主移动只从具备完整路线参数的动作中选择。

F-06 的物理尺寸策略只用于无有效保存尺寸的首次初始化。优先读取实际承载桌宠的显示器尺寸，主屏作启动定位后备。物理尺寸可靠时用于确定基准，否则按 256×256 DIP 和目标屏 DPI 换算为窗口像素。初始缩放默认 70%，因此当前回退路径为 179.2×179.2 DIP（物理像素随 DPI 取整）。跨屏沿用每屏 DPI 适配，保留用户缩放比例。物理尺寸探测和回退算法见 [G-03](G-03-architecture.md#首次尺寸与跨屏-dpi)。

## 3. 状态优先级与时间

使用相互独立的可见性、姿态、活动和集成状态，避免隐藏/聊天/吸边组合形成大量混合枚举。基础姿态为自由或吸边；活动为待机、自动移动、手动动作、拖拽。工作状态只改变基础待机选择，不阻止手动动作。

优先级：退出/恢复处理 > 隐藏 > 拖拽 > 手动动作 > 自动移动/待机。新手动动作替换旧手动动作；一次只播放一个主动作，不积累点击队列。自动动作等当前非循环动作结束。手动动作结束后按当前姿态与任务状态重选基础动画，不恢复过期位移。鼠标经过不打断动作。

使用单调时钟计算动画与移动，墙钟仅作历史显示。隐藏/休眠恢复重建播放基准，禁止追赶所有漏帧。气泡优先级：审批/输入提示 > 失败 > 完成 > 进度 > 普通互动；主动额度/设置预览单独显示，不由后台进度覆盖。隐藏期间继续必要的后台任务处理但不弹气泡，恢复只显示最新待处理/终态摘要，不重放积压音效。

可见性按手动隐藏和当前全屏条件共同决定。托盘允许在手动隐藏或穿透时操作，且仅在存在可用的恢复入口时启用这两种模式。拖拽捕获丢失或窗口隐藏时结束本次手势，取消尚未派发的单击及本次吸边判定。

## 4. 集成功能

| ID | 正常行为 | 降级与验收 |
| --- | --- | --- |
| F-10 能力/连接 | 用户开启后探测版本、认证状态与能力；分别显示任务、会话、审批、额度可用性 | 缺客户端、未登录、未知版本分别提示；无能力不发请求；普通桌宠可用 |
| F-11 任务观察 | 仅读取公开进展/最终结果/等待状态；点击通知查看详情或回到来源应用 | 首次同步建立水位不播报旧完成项；重连不重复成功提醒；不读取推理或成功工具原始输出 |
| F-12 会话 | 输入、流式回复、历史查看、同模式会话复用；中文输入、复制、滚动、长文本 | 一会话最多一条执行中 turn；保留草稿；关闭历史窗不取消任务；失败不伪装成最终答案 |
| F-13 模式/审批/取消 | 普通聊天只读；工作模式明确工作目录和权限；审批由用户明确处理；取消有处理中与确认结果 | 观察到外部任务等待审批只引导原客户端；未知审批类型不自动同意；重连不重发有副作用的请求 |
| F-14 额度 | 主动查询，显示剩余量、更新时间与过期状态；0% 正确可读 | 认证失败不自动重试；暂时断连最多一次查询重试；不把缓存显示为实时 |
| F-15 历史/迁移 | 本地按 provider/会话隔离；显式迁移旧记录，标明未完成任务 | 损坏历史保留备份；读取失败不可用空数据覆盖；重启不自动继续旧工作 |

首个适配器内部区分任务观察和主动会话传输；任务观察不获得执行权。聊天与工作模式不能隐式共享更高权限会话；切换模式创建独立会话，明确保留或复制上下文的方式。P3 前根据支持的客户端版本冻结能力表；当前不承诺 ChatGPT 与 Codex 登录/历史完全互通。

客户端显示名、连接提示和专属文案按客户端身份解析，缺项使用通用提示。未连接或禁用时使用中性标识。任务来源标识随事件来源，历史记录可保留原客户端标识。客户端品牌展示与连接能力分别确定，界面只有在探测确认后才显示相应能力可用。

通知去重键为 provider + session + turn + event-kind + event-id（无事件 ID 时使用稳定内容摘要）。首次启动仅通知正在等待用户处理的任务；旧完成项存档不播报。中间工具失败与整轮失败分别展示，只有明确 completed 才发成功提示。

## 5. 数据与非功能需求

F-16：配置、历史、日志、缓存和安装资源分离；迁移不改写原文件；日志默认不含提示词、回复、密钥、完整工具参数；诊断导出由用户发起。无自动上传、遥测或网络更新检查。

F-17：动画按帧期限唤醒、UI 按变化重绘、缓存与队列有界。目标首次可交互 ≤2s、输入响应 p95≤100ms、稳定播放丢帧率 <1%；测量条件详见 [G-06](G-06-validation.md)。

F-18 素材包替换预留。整套角色的图像、动画、音效及角色专属文本通过本地版本化素材包和稳定资源键加载。用替代样本包验证同一构建可读取不同资源布局。缺失的可选音效可静音，可选文案回退通用文案。启动依次尝试配置指定的素材包与默认素材包，两者都无法加载时退出。首期通过设置或配置指定素材包，重启时加载。设置使用包内角色图片和通用角色名，单击使用包内互动音效。

## 6. 延后项与变更规则

DSH、其他平台、多个角色、在线素材商店、自动更新、跨设备历史、完整 Markdown/终端执行视图均延后。变更功能行为或默认值时，同步对应需求编号、配置契约和验收用例。
