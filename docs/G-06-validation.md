## 2. 分层验证

纯逻辑：可控单调时钟、固定随机种子，验证移动、动作优先级、隐藏恢复、通知去重和配置迁移。契约：合成 FrameSource/IntegrationProvider 故意发送迟到、乱序、重复、损坏和缺能力事件，验证 generation、request/turn 绑定与背压。

媒体：自有渐变/透明边缘、长动作、移动样本；无效 manifest、超预算单页、损坏校验和、读取失败、取消与设备不支持。黑/白/棋盘/彩底对照 RGB 和 alpha；PNG 先对参考解码，再比较 BC7，平均误差不能替代边缘观察。

Windows 实机：透明、置顶不抢焦点、输入穿透、托盘恢复、中文输入法、剪贴板、文本选区、长文本滚动、全屏、锁屏、休眠、GPU/surface 恢复。至少一台核显/普通笔记本与另一 GPU/驱动环境；100%/125%/150%/200% DPI 与混合 DPI。缺设备时记未验证并缩小支持范围。

首次尺寸实验（P2）：对照两块同分辨率而物理尺寸不同的显示器，记录实际面板可视宽高、探测值、对应显示目标、缩放、初始 DIP/像素和工作区约束。验证候选算法的毫米尺寸、比例和边界，确认有效尺寸偏好优先，并覆盖缺失、零值、实例错配及查询超时的回退。探测不可靠时记录原因，并验收 256 DIP 路径。跨屏呈现的已有实测见 [R-03](records/R-03-p1a-window-input.md#混合-dpi-跨屏)。

CI：Windows locked build、fmt、clippy、现有纯逻辑/契约测试；自有 fixtures。GUI 截图/实机证据另存节点记录。无需为本轮纯文档改动建立镜像实现的测试套件。

## 3. 性能实验与预算

| 项目 | 初始目标/口径 | 冻结节点 |
| --- | --- | --- |
| 首次可交互 | 进程启动至首帧且拖拽/菜单可用 ≤2s，不以占位单帧替代交互 | P0 口径，P1a/P1b 测量 |
| 输入响应 | 输入事件至可见反馈 p95 ≤100ms；另报 p50/p99 | P0 |
| 播放丢帧 | 24/30fps 原时间序列；稳定播放 <1%，报告缺失应呈现帧/应呈现帧数 | P0 |
| CPU 素材缓冲 | 初始 32 MiB，包含读取/解码/排队中的分配 | P1b |
| GPU 素材池 | 初始 64 MiB，surface/UI/驱动另外报告 | P1b |
| 全进程内存/完整包体 | 待测，不编造已达标上限；P0 建基线，P1b 冻结数值与依据 | P1b，未填不能退出 |
| 隐藏/稳定性 | 无持续动画提交/无效解码上传；2h 常驻、100 次切换无持续资源增长 | P4 |

记录 CPU/GPU/驱动、OS、DPI、构建 commit/Release 参数、素材哈希、features、进程树。CPU 定义为进程 CPU 时间/墙钟时间（一个逻辑核为 100%）；主进程、解码参照进程和可选集成子进程分列。内存记录 private bytes、working set、峰值、GPU 资源/共享显存，不能只看工作集。

启动至少 10 次，报告中位数与范围，区分进程冷启动和系统文件缓存条件；稳定场景预热 2 分钟、采样 10 分钟、至少 3 轮。场景覆盖待机、自动移动、拖拽、切换、聊天和隐藏；记录 CPU、GPU 活跃时间、唤醒、I/O、帧间隔、上传延迟。构建成本分首次下载、干净/增量 Release 时间、峰值内存与工具链体积；完整部署体积包括资源/字体/运行库。

实验分组：

1. 同素材/尺寸/时序/缓存策略的 Python 与 Rust 参照，只比较功能已对齐部分；不能用空骨架对完整旧版。
2. 同一语言同一渲染路径的全缓存与有界缓存，单独归因；内存不足时记录未完成，双方改用相同子集。
3. 同一 Rust 播放器的参考 FFmpeg、PNG/RGBA、BC7，固定尺寸、帧数、预算，测离线转换成本、画质、包体和运行负载。
4. 最终完整程序重测，不能将模型执行成本算成桌宠开销；无 FFmpeg 运行时目标以干净机包内容和进程调用记录验证。

关键指标回退 >10% 调查；噪声范围内记“未证实提升”。BC7 成为默认需视觉通过、预算通过、至少一项 CPU/唤醒或帧延迟稳定改善，且其他关键指标无未解释回退；若不成立则选择更简单的无损有界路径或重新评估。记录组合方案差异，不将全部收益归因 Rust。

## 4. 发布门槛与回退

P4 必须有需求矩阵结果、窗口/设备记录、所有实际入包动作验证、性能报告、迁移/回退演练、干净机离线验证、版本/哈希/许可清单、已知限制。原版“35 段”是历史素材规模，候选包以实际可分发清单为准；删减必须明确告知并修改范围，不能遗漏后宣称完整迁移。

若外部集成只支持部分客户端版本，发布说明明确版本和能力；不兼容时退出对应功能。回退使用上一可运行检查点、原配置/历史备份和匹配素材包；不要求旧程序读取新 schema。存在未解决数据丢失、越权审批或不可恢复退出问题时不得标为候选就绪。
