# 当前开发基线

当前主线已完成 Windows 普通桌宠和只读客户端查询的本机开发验收。对话仍处于独立接口验证阶段，首次正式发布同时需要通过 Windows 候选验收和客户端同会话验收。 [实施主线](roadmap.md) · [首次正式发布门槛](../development/release.md#首次正式发布门槛)

| 范围 | 已有能力 | 后续验证 |
| --- | --- | --- |
| Windows 普通桌宠 | 支持透明命中、自主移动、吸边、探头、隐藏恢复和换包。快捷面板、设置和客户端面板使用 WinUI 3，原生托盘提供恢复入口 | 干净机、严格断网、混合 DPI、长时运行及发行包回退。WinUI 真实中文 IME 随输入功能验证。 [Windows 实测](validation.md#m1-winui-3-正式替换) |
| 素材与播放 | 统一使用 v2 PNG 与显式语义绑定。320 px 十动作包是默认候选，39 动作包供开发验证。按页加载并对缺页做故障回退 | 公开分发范围、来源及许可仍待确认。放大画质和运行成本按同源、同配方和实际窗口尺寸比较。 [素材与成本](validation.md#默认素材与成本) · [制备方式](../../assets/README.md) |
| 配置与旧数据 | 使用 TOML 和原子保存，支持显式导入已核验的旧偏好或历史，保留原件与可校验的回滚记录 | 发布前用实际安装组合验收配置升级与回退。 [配置与迁移契约](../development/runtime-v2.md) |
| 客户端 | ChatGPT 桌面连接默认启用，速览和连接详情共享套餐与 Codex 额度。使用合成第二来源验证并列和隔离。Codex 同会话已有单次发送、流式结果和属主队列的限定样本 | 复验 M2 网络断连，接入真实 DSH。M6 继续验证队列恢复、账号与工作区隔离、版本兼容，并分别确认普通 Chat 和 Work 的能力。 [当前验证范围](validation.md#当前审查与交接) |
| 平台与构建 | 核心逻辑在 Windows 和 Kali WSL2 上已有测试。Windows 图标资源由 Windows 主机构建，托管 Windows 检查按需手动触发 | Linux 桌面后端按选定环境实施，在原生桌面验收窗口、输入、托盘和恢复。 [Linux 验证](validation.md#linux-风险验证环境) · [构建工作流](../development/workflow.md) |

性能目标继续跟踪。Windows 正式 WinUI 3 设置回归中，待机与打开设置的进程合计 private bytes 约 440 MiB 和 526 MiB，仍高于 D06 的调查目标。M3 按实际发行组合和设备重新验收。 [M1 设置实测](validation.md#m1-winui-3-正式替换) · [性能目标](../design/performance.md)

## 验证证据

按运行日期、环境、构建特性、素材版本和结果记录开发验收。使用[工程验证记录](validation.md)查结论和复测范围，使用[本地产物说明](../../artifacts/README.md)定位机器日志。发行证据随对应附件或持久存储保存，并登记哈希与位置。
