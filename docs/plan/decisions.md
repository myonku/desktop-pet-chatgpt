## 已确认方向

2026-11-16，M2 将 Codex 额度与套餐纳入同一次查询。11 月 18 日的开发版本采用默认启用的 ChatGPT 连接开关，打开速览自动刷新。M2 断网验收继续后置，优先推进 M6 的 Windows 同会话验证。 [现行速览复验](validation.md#m2-windows-默认连接与自动刷新) · [后续主线](roadmap.md)

2026-11-14：以当前原型重新规划。先推进 Windows 普通桌宠与 ChatGPT 桌面客户端基础信息查询，第二客户端为 DeepSeek Harness 桌面版。

2026-11-15：M1 以开发验收收尾，暂缓附件交付和发布。首次正式发布须具备完整的 Windows ChatGPT 客户端集成，包括桌宠对话。 [发布门槛](../development/release.md#首次正式发布门槛)

2026-11-15：聊天窗口定位为面向客户端会话的轻量客户端，套餐和诊断移入辅助详情。模式、模型、上下文统计按接口能力逐项纳入。 [会话布局](../design/panels.md#聊天窗口与会话)

2026-11-14：角色右键打开快捷面板，双击查看信息速览，复杂业务进入独立聊天窗口。托盘负责程序管理与恢复，复杂配置进入独立设置中心。UI 现代化限 Windows 面板，角色沿用现有渲染。Linux 可以独立实现面板前端。框架选型见 D27，交互细节见[面板设计](../design/panels.md)。

2026-11-15 确认 D17。每个平台为 ChatGPT 和 DSH 各设一个适配器，两个客户端可独立配置并同时接入。信息速览汇总各客户端，聊天窗口按客户端切页。首期每种客户端最多连接一个来源。 [连接设计](../design/integrations.md#连接设置与来源选择)

2026-11-14 已确认按字段决定是否需要绑定桌面前台账号。套餐可以按 App Server 登录来源交付，后续对话须显式绑定用户账号及会话。 [接入验证](validation.md#chatgpt-接入来源)

2026-11-14：D07 已确认开发与首发统一采用 v2 PNG。读取器、校验器、制备、装配和回归均使用 v2。D19 确认未对外发布的开发迭代直接采用当前设计。 [素材协议](../design/assets.md)
