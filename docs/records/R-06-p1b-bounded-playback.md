# R-06 · P1b-02 有界播放

2026-11-09，基于 `fd18b1e`，状态为完成。实现和本记录同一提交。

## 实现与预算

- 启动时按环境配置打开本地包，使用清单中的首个动作作为播放实验。后台线程按需读取、校验及解码一页，在跨页前一帧预取。事件线程用单调时钟从逐帧持续时间定位目标帧，晚到页保留上一帧，恢复后直接选当前帧。隐藏取消当前代次，恢复从动作开头计时。迟到结果释放请求槽后丢弃。
- CPU 侧同时保留显示页与一个待用页或请求结果，每页最多 6 MiB，含 BC7 压缩块和命中用解码像素。PNG 单次输入及解码器工作限额各 3 MiB。GPU 单槽重复使用同尺寸同格式的纹理，后续上传前等待前一笔上传完成，更换尺寸或格式前等待旧纹理提交完成。页池与上传在初始 64 MiB GPU 预算内，单次等待上限 250 ms。全进程与驱动分配留待 P1b-03 测量。
- 纹理页按帧矩形采样，直通原始 BC7 块上传。BC7 的命中像素通过 Rust 块解码得到，PNG/RGBA8 直接使用同一页像素生成命中区域。BC 功能不可用或当前页没有 BC7 时使用 RGBA8。坏包、超预算或播放读取失败进入内置占位。
- 原型按包换入动画资源。音效播放、文本展示与产品动作选择在对应的后续节点接入。

## 复现与结果

按 [R-05](R-05-p1b-offline-packs.md) 生成两个样本包，运行下列命令。把 `dawn` 改为 `dusk` 后重新启动，或改用 `rgba8` 与 `png`。

```powershell
$env:DESKTOP_PET_PACK = (Resolve-Path target/p1b-fixtures/dawn).Path
$env:DESKTOP_PET_FORMAT = 'bc7'
cargo run --locked
```
