# R-04 · P1a-03 中文预览与恢复

2026-11-09。状态为完成。实现与本记录同一提交，基于 `9f95762`。

## 实现

- 右键和托盘菜单打开单个独立 egui 预览窗口。窗口包含多行输入和可选中、可滚动的长文本，输入与剪贴板由 egui-winit 路由。中文字体从系统自带的微软雅黑读取。
- 托盘可隐藏或恢复桌宠，隐藏时跳过桌宠绘制。托盘重建失败时恢复桌宠可见和输入。预览按输入事件和 egui 的重绘期限唤醒。
- Windows 休眠恢复事件触发重绘。桌宠 surface 遇到 Lost、Outdated 或 Timeout 时有限重试，设备丢失时尝试重建一次。辅助窗口使用独立 painter。

## 已验证

- Windows 锁定 Debug 构建、格式检查、Clippy 和现有 Rust 测试通过。
- 本机单屏打开透明样本，经右键打开预览，确认中文字符可输入并显示，长文本滚动后行号变化。关闭预览后桌宠保留，原型可经菜单退出。字符输入使用自动化文本注入。

## 维护者实测与故障注入

- 维护者确认前两项实机用例通过，反馈中文 IME 输入和候选正常，隐藏、恢复、鼠标穿透及休眠唤醒状态符合预期。
- 临时诊断构建在绘制结果入口注入一次 `SurfaceError::Lost`。下一次绘制返回成功，桌宠呈现 320×320 首帧并继续运行。
- 向事件循环注入 `PetDeviceLost`。首次事件重建设备与 surface，恢复呈现首帧。第二次事件输出恢复后再次丢失的诊断，进程以代码 1 退出。
- 将辅助窗口从 125% 屏移到 100% 屏，客户区从 700×575 变为 560×460，中文界面正确重绘，滚动后内容更新。
