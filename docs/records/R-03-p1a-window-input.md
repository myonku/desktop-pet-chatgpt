# R-03 · P1a-02 窗口输入

日期 2026-11-07，基于 P1a-01 `9517a0c`。本记录随窗口输入实现提交。

## 实现

- 解码一次 PNG，渲染与命中共用 RGBA 像素。按 WGSL 最近像素取样的边界生成 Win32 窗口区域，排除 alpha 为零的像素。区域按客户区物理尺寸重建，透明处直接落到下层进程。依据 [SetWindowRgn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn)。
- 窗口启动不激活。普通鼠标按压通过 `WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE`。左键越过系统 DPI 拖动阈值后在原生鼠标消息中移动，移动使用 `SWP_NOACTIVATE`。DPI 改变时按新比例修正抓取点，winit 调整客户区大小。
- 样本右键和托盘共享菜单。全窗口穿透借用 winit 的 Windows 鼠标命中开关，保留 DirectComposition 画面。托盘注册失败时禁用穿透，右键菜单仍提供退出。任务栏重建时尝试重新注册，失败则恢复原型输入。依据 [Shell_NotifyIconW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw)。

## 已验证

参考机 Windows 11 22631、RTX 4060 Laptop GPU，单屏 175%，客户区 448×448。使用不同进程的计数窗口作为下层目标，查看 Windows 窗口归属、点击计数和实机截图。

| 检查 | 结果 |
| --- | --- |
| 启动焦点 | 在无新控制台窗口的启动方式下，下层测试窗保持前台，原型置顶呈现。 |
| 透明与可见像素 | 点击色带最左侧全透明列，下层计数加一。半透明和不透明采样点的 HWND 属于原型。 |
| 拖拽 | 观察到原型由物理坐标 (132,132) 移至 (228,211)，与注入的 55×45 逻辑像素拖动相符。下层点击计数保持不变。 |
| 全窗口穿透 | 开启后原型仍可见，透明、半透明及不透明采样点归属下层窗口。不透明灰阶上的实点使下层计数加一。 |
| 托盘恢复与退出 | `Shell_NotifyIconGetRect` 返回成功。夹具向原型派发同格式托盘回调并在原型附近弹出菜单。再次选择有勾选的穿透项后，可见区域恢复命中且可拖动。选择退出后窗口关闭，进程返回 0。 |
| 命中比例 | Rust 回归测试对照 100%、125%、150%、175%、200% 的像素中心与着色器取样索引。 |
