## P2-01 实施顺序

1. 用自有合成素材生成一套最小包，至少包含循环待机、一次性互动、定向移动和吸边姿态。打乱动作列表顺序，另准备缺可选动作的样本，验证动作按 ID 绑定及降级。P0 的[动作盘点和旧行为](../p0/R-01-p0-baseline.md#p0-02--旧行为)作为迁移输入。首批旧动作的映射、变换和轨迹在接入代表素材前逐项记录。
2. 复用现有页读、透明呈现与托盘路径，先跑通待机 → 互动 → 待机。明确动作完成、缺页等待上限、取消与恢复的事件，再接管拖拽和自主移动的位置仲裁。用可控时钟覆盖单击延迟、双击抑制、动作被打断和隐藏恢复。
3. 接通实际窗口的屏幕/DPI 与工作区变化。物理尺寸探测可单独复测，探测失败时用 256 DIP 基准乘初始比例继续验收。启动已读取 `initial_scale_percent` 和 `pack_path`，默认比例为 70%。配置尺寸优先级、运行时写回、重启恢复和一键恢复随 P2-02 复验。

现有素材导入器用于单动作、固定帧率的 P1 对照。P2 先用合成包跑通主线，并为拟移植的代表动作形成可复现的多动作装配记录。全量素材的处理方式、实测包体与可分发范围应在 P4 装配前明确。
