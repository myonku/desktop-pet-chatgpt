# 当前版本使用说明

当前是 Windows 开发版本，支持普通桌宠，以及可选的 ChatGPT 套餐和 Codex 额度查询。Linux 桌面、DSH 查询和对话仍在计划中。

## 运行与素材

Windows 面板需要安装与程序架构一致的 Windows App Runtime 2.4 或更高的 2.x。 [微软下载页](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads)

从源码运行见[开发说明](../development/workflow.md)。开发构建从启动目录的 desktop-pet.dev.toml 读取设置；产品构建从 `%LOCALAPPDATA%/DesktopPetChatGPT/config.toml` 读取和保存。完整字段见[当前配置契约](../development/runtime-v2.md#配置与启动)。

产品需要有效素材目录，默认位置是 EXE 旁的 `resources/default/`，其中直接包含 `manifest.json`。换包时可从设置选择目录，检查名称、版本和动作数，保存后重启。校验不通过时，之前保存的素材路径继续生效。相对路径以配置文件所在目录为准。支持 v2 PNG 目录包，ZIP 需要先解压。 [素材契约](../development/runtime-v2.md)

配置包无法首启或其待机动作在运行中损坏时，程序尝试默认包并保留已保存的目录。可在设置中查看当前状态，修复或重新选择素材目录。两个包都不可用时会提示并退出。配置损坏时会询问是否先备份再恢复；拒绝则保留原件并退出。

## 操作

单击角色可互动，按住可见区域拖动，靠近工作区左右边缘释放可吸附。单击吸边角色可切换探头。

- 右键角色打开快捷操作栏。常驻项为「聊天窗口」、「+ 缩放 -」、「动作预览」和「快捷设置」，吸边时还有「展开桌宠」。两个子菜单在栏内展开，可纵向滚动。「快捷设置」里可切换自移动、音效和全屏隐藏，也可打开「全部设置」。
- 双击角色打开圆角信息速览。两个浮层在拖动或自主移动时都会带惯性跟随角色，点击空白桌面时也会保留。切到其它应用窗口或在浮层内右键可收起。再次右键角色可收起快捷栏，再次双击角色或在速览内按 Esc 可收起速览。
- 右键托盘打开程序管理菜单，可显示或隐藏角色、恢复鼠标控制、切换音效／自移动／全屏隐藏、打开聊天窗口和设置，或退出。
- 设置中心采用固定尺寸，内容可纵向滚动。底部的「应用并保存」提交编辑过的字段，关闭时撤销未提交的预览。快捷面板或托盘修改同一字段时，可明确覆盖冲突，也可关闭设置保留当前值。开发构建的设置仅影响本次运行。

“启动时隐藏”在下次启动生效，托盘可以恢复角色。全屏自动隐藏与手动隐藏分开；全屏结束不会撤销手动隐藏。鼠标穿透可从托盘撤销。

设置中心的「自主移动」提供「关闭」「仅水平」和「全方向」。默认「全方向」，使用全动作包时桌宠偶尔会斜向飞行。标准十动作包只支持水平移动。选择「关闭」会保留斜向偏好，从托盘或快捷设置重新打开自移动时会恢复上次的移动范围。

角色窗口的默认初始缩放为 100%。已保存的窗口尺寸优先，其次是配置中的初始缩放。使用全动作素材包时，桌宠有多种待机、互动和移动表演。关闭自移动后仍可原地切换待机动作。动作预览显示素材包提供的短名称。任务气泡设置当前可保存，但尚无真实任务通知。登录自启是可选项。 [全动作包使用说明](../../assets/README.md#v2-全动作开发包)

## 查询 ChatGPT 套餐和 Codex 额度

1. 「连接到ChatGPT」默认勾选。要停用，在设置中取消勾选并应用。
2. 在当前 Windows 会话运行 ChatGPT 桌面客户端，双击角色打开信息速览。桌宠自动连接；速览打开期间会自动读取并每分钟更新套餐和额度。
3. 速览按客户端分卡显示订阅和客户端版本。「Codex 额度」右侧显示最近一次刷新时间，各额度窗口的进度条旁显示剩余百分比和重置时间。刷新和重置时间均使用本地时区。出现「需认证」时，确认账户已登录后等待自动刷新，也可在聊天窗口中手动刷新。
4. 点击「打开聊天」进入聊天窗口。目前此窗口用于只读查询和连接管理。隐藏桌宠时窗口仍可使用，可在其中手动刷新或清除缓存。

套餐和额度保留在内存，5 分钟后标记过期。账户查询失败时，同一来源保留的上次数据标为过期。仅额度查询失败时，界面显示本次套餐和额度错误。来源断开、切换、停用或清除缓存时清除旧值。当前实测范围为 Windows 11 上的 ChatGPT MSIX 26.1111.2228.0 与配套 CLI 0.169.0-alpha.11.1。 [现行速览复验](../plan/validation.md#m2-windows-默认连接与自动刷新) · [真实额度验证](../plan/validation.md#m2-windows-codex-额度)

## 旧数据导入

先退出桌宠，再在产品 EXE 所在目录运行：

```powershell
.\desktop-pet-chatgpt.exe migrate config-json
.\desktop-pet-chatgpt.exe migrate bailong-preferences
.\desktop-pet-chatgpt.exe migrate bailong-history
```

按来源选择需要的命令，不必全部执行。已有目标会报告冲突；原件保留，命令返回迁移 ID，可用 `migrate rollback <migration-id>` 回滚未被后续修改的结果。上游导入仅针对已核验的 v0.5.1 数据；导入历史不会恢复任务，也不表示已经提供历史查看或会话集成。
