# 当前版本使用说明

当前是 Windows 开发原型，已实现透明动画、点击互动、拖拽、自移动、吸边与探头、缩放、托盘、隐藏、音效和设置。Linux、ChatGPT/DSH 数据查询和对话尚未实现；相关菜单/偏好中的占位不代表可用能力。

## 运行与素材

从源码运行见[开发说明](../development/workflow.md)。开发构建从启动目录的 desktop-pet.dev.toml 读取设置；产品构建从 `%LOCALAPPDATA%/DesktopPetChatGPT/config.toml` 读取和保存。完整字段见[当前配置契约](../development/runtime-v1.md)。

产品需要一个有效素材目录，默认位置是 EXE 旁的 `resources/default/`，其中直接包含 manifest.json。可通过配置的 pack_path 指定另一包；相对路径以配置文件所在目录为准。当前改包后需要重启，不支持把任意图片、视频或 ZIP 直接当作素材包。

配置包不可用时尝试默认包，两者都不可用则提示并退出。配置损坏时会询问是否先备份再恢复；拒绝则保留原件并退出。

## 操作

单击角色可互动，按住可见区域拖动，靠近工作区左右边缘释放可吸附。单击吸边角色可切换探头，通过菜单展开。右键与托盘共用菜单，可预览动作、开关自移动/音效、隐藏或打开设置；具体动作取决于素材包。

设置可预览尺寸，应用后保存产品偏好；直接关闭撤销未确认的预览。打开菜单也会先关闭设置并撤销未确认改动。开发构建的设置仅影响本次运行。

“启动时隐藏”在下次启动生效，托盘可以恢复角色。全屏自动隐藏与手动隐藏分开；全屏结束不会撤销手动隐藏。鼠标穿透可从托盘撤销。

角色窗口的默认初始缩放为 100%。已保存的窗口尺寸优先，其次是配置中的初始缩放。任务气泡设置当前可保存，但尚无真实任务通知。登录自启是可选项。

## 旧数据导入

先退出桌宠，再在产品 EXE 所在目录运行：

```powershell
.\desktop-pet-chatgpt.exe migrate config-json
.\desktop-pet-chatgpt.exe migrate bailong-preferences
.\desktop-pet-chatgpt.exe migrate bailong-history
```

按来源选择需要的命令，不必全部执行。已有目标会报告冲突；原件保留，命令返回迁移 ID，可用 `migrate rollback <migration-id>` 回滚未被后续修改的结果。上游导入仅针对已核验的 v0.5.1 数据；导入历史不会恢复任务，也不表示已经提供历史查看或会话集成。
