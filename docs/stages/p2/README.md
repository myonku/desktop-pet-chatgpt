## P2-03 开工前调整

2026-11-12 在 `codex/p2` 的 P2-02 检查点 `ebf6b58` 上统一产品与开发的 TOML 读取规则。开发构建通过 `development` feature 决定文件优先级和可用字段。坏配置启动时由用户确认是否备份并覆盖，旧 JSON 留作显式迁移的候选输入。

素材协议 v1 以当前包为基线，后续独立演进。启动按配置包、默认包的顺序加载，首个待机页可用后才显示角色。两处都失败时退出。现行配置与素材规范见 [G-05](../../G-05-contracts.md)。

Windows 本地复测通过格式检查、Clippy、锁定 Debug/Release 构建、默认及全 feature 测试（各 20 项），以及 `dawn`、`dusk`、`p2-behavior` 和 `p2-idle-only` 的分发校验。设置回归结果在 `artifacts/validation/p2/runs/startup-recheck-1794451470591/result.json`。另用隔离目录验证了两类构建的配置选取、损坏首帧切换默认包、无可用包退出以及确认和拒绝两条恢复路径。启动日志在 `artifacts/validation/p2/runs/startup-smoke-1794451322039006000/`。

核心回归通过 125% 与 100% 双屏尺寸、桌宠行为、缺可选动作、后续互动页损坏回到待机及坏首帧无备选包时退出。参照构建对 `dawn` 进行 PNG 冒烟，首个素材帧为 331.69 ms，呈现 90/90 帧。两项结果分别在 `artifacts/validation/p2/runs/startup-final-1794451556470/core/result.json` 和同一运行目录的 `playback/result.json`。托管 Windows CI 待触发。

## P2-01 实施顺序

1. 用自有合成素材生成一套最小包，至少包含循环待机、一次性互动、定向移动和吸边姿态。打乱动作列表顺序，另准备缺可选动作的样本，验证动作按 ID 绑定及降级。P0 的[动作盘点和旧行为](../../archive/p0/R-01-p0-baseline.md#p0-02--旧行为)作为迁移输入。首批旧动作的映射、变换和轨迹在接入代表素材前逐项记录。
2. 复用现有页读、透明呈现与托盘路径，先跑通待机 → 互动 → 待机。明确动作完成、缺页等待上限、取消与恢复的事件，再接管拖拽和自主移动的位置仲裁。用可控时钟覆盖单击延迟、双击抑制、动作被打断和隐藏恢复。
3. 接通实际窗口的屏幕/DPI 与工作区变化。物理尺寸探测可单独复测，探测失败时用 256 DIP 基准乘初始比例继续验收。启动已读取 `initial_scale_percent` 和 `pack_path`，默认比例为 70%。配置尺寸优先级、运行时写回、重启恢复和一键恢复随 P2-02 复验。

现有素材导入器用于单动作、固定帧率的 P1 对照。P2 先用合成包跑通主线，并为拟移植的代表动作形成可复现的多动作装配记录。全量素材的处理方式、实测包体与可分发范围应在 P4 装配前明确。
