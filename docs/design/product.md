# 产品范围与用户路径

状态：首发优先级和面板方向已由维护者确认。当前实现见[使用说明](../user/guide.md)，具体待选项见[决策表](../plan/decisions.md)。

## 产品目标

一个以普通桌宠为基础、可替换角色素材、支持 Windows 与 Linux 桌面环境、能够连接 ChatGPT 桌面客户端及 DeepSeek Harness（DSH）桌面版的常驻程序。客户端数据是可选增强，普通桌宠不要求登录、网络或模型服务。

首个可发布版本：**Windows 普通桌宠 + ChatGPT 桌面客户端基础信息查询**。Linux 随后推进。DSH 保留独立适配器设计，其真实实现排在首个适配器之后，和 Linux 的先后仍待选。对话后置，首发不要求任务执行、审批、取消和完整历史管理。

## 能力边界

| 能力 | 首发范围 | 后续 / 排除 |
| --- | --- | --- |
| 角色行为 | 单实例、单角色、待机/点击/拖拽/移动/吸边、隐藏/恢复、音效、缩放 | 多宠并存、养成系统不进入当前主线 |
| 定制 | 本地整包替换；校验、预览、应用、失败恢复；基础包可独立使用 | 编辑器、素材商店、在线自动下载后置 |
| 信息查询 | 显式启用客户端、检测连接、手动刷新、展示有来源和时效的基础字段 | 额度、账户摘要、当前任务等按字段证据纳入，不承诺全部存在 |
| 主动提醒 | 首发只展示查询结果和连接变化；是否后台定时刷新待选 | 任务完成气泡、历史任务扫描不是首发必做 |
| 对话 | 首发无发送入口 | 后续单独验收草稿、流式、历史、取消与审批 |
| 平台 | Windows 优先；从现在隔离平台假设 | Linux 分桌面环境支持，不能用“Linux”一词承诺全部行为一致 |
| 发布 | 可离线安装的版本化附件、来源与兼容清单、手动升级回退 | 自动升级、云同步不进入首发 |

## 完整用户路径与验收

| 路径 | 用户可见结果 | 失败边界 |
| --- | --- | --- |
| 首次启动 | 不配账号也能看到角色、拖动、打开设置并退出 | 默认包应随发行组合可获得；缺包时明确定位原因，不能启动成不可操作的隐形进程 |
| 换角色 | 选择本地包 → 校验 → 查看角色名/预览/尺寸与兼容性 → 应用 | 首发推荐确认后重启生效，旧包在新包成功前保留；不要求热切换 |
| 连接 ChatGPT | 在设置启用 → 选择/确认客户端实例 → 显示实际支持字段 | 未安装、版本不支持、需认证分开说明；不能猜测用户是哪一个账号 |
| 查信息 | 双击角色打开信息速览 → 手动刷新 → 查看值、来源与更新时间 → 按需展开详情 | 清楚标记未知、过期或不可用字段，提供相应的连接入口 |
| 隐藏与穿透 | 有可发现的恢复入口；后台查询按明确策略继续或暂停 | 托盘缺失时禁用会使用户失联的隐藏/穿透组合，提供普通窗口入口 |
| 升级 / 回退 | 保留用户偏好，旧安装可恢复 | 新 schema 不让旧程序静默写坏；恢复对应数据快照，不自动重跑任务 |

普通行为的优先级保留为：手动拖拽/操作 > 显式预览 > 姿态/自动行为；客户端状态只提供可撤销的表现意图，不能中断拖拽或持续强制角色移动。关闭自移动不影响手动预览。

## 界面设计边界

右键角色打开快捷面板，集中客户端入口和缩放、自移动等便捷操作。双击进入当前客户端信息速览。需要持续阅读或输入时打开独立功能中心，共用导航和连接状态，按 ChatGPT 与 DSH 的实际能力提供页面。托盘承担程序管理和恢复，复杂配置进入独立设置中心。详见[面板与窗口交互](panels.md)。

保留用户明确设置优先。音效、自移动、自动隐藏的首发默认值，以及首次尺寸是否继续依赖 EDID，都需要在首发体验验收前选定；当前值见现行契约，不随提案悄悄变化。

## 什么才算交付

每个切片必须有可运行产物、完整用户路径、正常/失败结果和支持边界。文档、接口草图、假数据演示不能单独结项；验证只为决定方案或证明这条路径。每次只推进一条主线和一个有期限的风险调查，避免重新进入连续验证却没有产品增量的流程。
