# 产品范围与用户路径

状态：首发优先级和面板方向已由维护者确认。当前实现见[使用说明](../user/guide.md)，具体待选项见[决策表](../plan/decisions.md)。

## 产品目标

桌宠支持替换角色素材，目标平台为 Windows 和 Linux。用户可以独立启用 ChatGPT 桌面客户端和 DeepSeek Harness（DSH）桌面版，按各自的设置连接。两者同时可用时，速览汇总信息，聊天窗口一次展示一个客户端。普通桌宠可在无登录、离线的环境中使用。

首次正式发布须具备 **Windows 普通桌宠 + 完整的 Windows ChatGPT 客户端集成**，包含基础信息查询和桌宠对话。对话在独立切片中验收。DSH 保留独立适配器设计，其真实实现排在首个适配器之后，和 Linux 的先后仍待选。

## 能力边界

| 能力     | 首发范围                                                                       | 后续 / 排除                                                         |
| -------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| 角色行为 | 单实例、单角色、待机/点击/拖拽/移动/吸边、隐藏/恢复、音效、缩放                | 多宠并存、养成系统不进入当前主线                                    |
| 定制     | 本地整包替换；校验、预览、应用、失败恢复；基础包可独立使用                     | 编辑器、素材商店、在线自动下载后置                                  |
| 信息查询 | Windows ChatGPT 默认自动连接，速览可见时自动刷新套餐和 Codex 额度             | DSH 接入后与 ChatGPT 并列显示。额度、账户摘要、任务等按来源能力纳入 |
| 主动提醒 | 首发只展示查询结果和连接变化；是否后台定时刷新待选                             | 任务完成气泡、历史任务扫描不是首发必做                              |
| 对话     | 聊天窗口作为轻量客户端，用户可绑定已授权的客户端会话、阅读消息、发送并接收回复 | 模式、模型、上下文统计按客户端的真实支持范围逐项验收                |
| 平台     | Windows 优先；从现在隔离平台假设                                               | Linux 分桌面环境支持，不能用“Linux”一词承诺全部行为一致           |
| 发布     | 可离线安装的版本化附件、来源与兼容清单、手动升级回退                           | 自动升级、云同步不进入首发                                          |

## 完整用户路径与验收

| 路径        | 用户可见结果                                                                                             | 失败边界                                                                   |
| ----------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 首次启动    | 不配账号也能看到角色、拖动、打开设置并退出                                                               | 默认包应随发行组合可获得；缺包时明确定位原因，不能启动成不可操作的隐形进程 |
| 换角色      | 选择本地包 → 校验 → 查看角色名/预览/尺寸与兼容性 → 应用                                               | 首发推荐确认后重启生效，旧包在新包成功前保留；不要求热切换                 |
| 连接客户端  | 在设置中独立启用相应客户端。当前 Windows ChatGPT 默认启用并自动连接。每种客户端可连接一个独立来源，有多个候选时在该客户端内选择 | 安装、运行、连接和认证分别说明。一端断连时仍可使用另一端                   |
| 查信息      | 双击角色打开速览 → 查看各已启用客户端的值、来源和更新时间 → 按客户端刷新或展开详情                     | 清楚标记未知、过期或不可用字段，并提供对应的连接入口                       |
| 对话        | 打开聊天窗口 → 选择客户端并绑定已授权会话 → 发送并接收回复 → 回到该客户端核对同一会话                 | 切换客户端时保留各自的草稿和发送状态。断连反馈显示在对应会话               |
| 隐藏与穿透  | 有可发现的恢复入口；后台查询按明确策略继续或暂停                                                         | 托盘缺失时禁用会使用户失联的隐藏/穿透组合，提供普通窗口入口                |
| 升级 / 回退 | 保留用户偏好，旧安装可恢复                                                                               | 新 schema 不让旧程序静默写坏；恢复对应数据快照，不自动重跑任务             |

普通行为的优先级保留为：手动拖拽/操作 > 显式预览 > 姿态/自动行为；客户端状态只提供可撤销的表现意图，不能中断拖拽或持续强制角色移动。关闭自移动不影响手动预览。

## 界面设计边界

右键角色打开快捷操作栏，进入聊天窗口或调整缩放、自移动等。双击角色查看各客户端的速览。聊天窗口保留上次查看的客户端，并按其已验证的能力显示会话操作和连接详情。托盘承担程序管理和恢复，连接方式在设置中心管理。 [面板与窗口交互](panels.md)

保留用户明确设置优先。音效、自移动、自动隐藏的首发默认值，以及首次尺寸是否继续依赖 EDID，都需要在首发体验验收前选定；当前值见现行契约，不随提案悄悄变化。

## 什么才算交付

每个切片必须有可运行产物、完整用户路径、正常/失败结果和支持边界。文档、接口草图、假数据演示不能单独结项；验证只为决定方案或证明这条路径。每次只推进一条主线和一个有期限的风险调查，避免重新进入连续验证却没有产品增量的流程。
