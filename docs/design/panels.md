# 面板与窗口交互

2026-11-14 已确认交互方向与平台边界。本文描述目标设计。当前行为见[使用说明](../user/guide.md)，首发范围和待定选项见[实施主线](../plan/roadmap.md)与[取舍清单](../plan/decisions.md)。

## 入口与职责

| 入口 | 打开的界面 | 内容与关闭方式 |
| --- | --- | --- |
| 左键单击角色 | 角色互动 | 沿用点击动作与吸边探头。拖拽、单击和双击互斥。 |
| 右键角色 | 快捷面板 | 桌宠旁的功能栏或浮层。提供当前客户端入口、信息速览、打开功能中心，以及缩放、自移动等少量便捷操作。点击外部或 Esc 收起。 |
| 左键双击角色 | 信息速览 | 桌宠旁的临时信息卡。显示选中客户端、连接状态、实际可用字段、来源和更新时间，提供手动刷新和展开详情。 |
| 快捷面板、速览中的“展开”，或托盘入口 | 功能中心 | 独立可缩放窗口。承载客户端详情，后续加入任务、对话及完整会话流。支持显式关闭或切回前台，保留窗口位置。 |
| 托盘右键 | 程序管理菜单 | 保留程序级常用开关、进入设置、恢复与退出。 |
| 托盘菜单或快捷面板的“更多设置” | 设置中心 | 独立普通窗口。管理外观与行为、素材、客户端连接、自启、通知与诊断。显式应用或取消。 |
| 客户端结果或任务事件 | 通知气泡 | 简短、非激活、自动收起。后续支持从通知打开对应详情。 |

快捷面板和速览可复用同一浮层容器。首发先用小型浮层，固定浮层与悬停提示可在实机验证后决定。复杂配置集中在设置中心，快捷面板以客户端相关入口为主，缩放和自移动仍可离线使用。

托盘菜单默认保留显示／隐藏角色、关闭鼠标穿透或恢复控制、打开功能中心、音效／自移动、设置及退出。关于和诊断可收进设置。托盘菜单和快捷面板共用自移动等应用命令，各自组织入口。托盘不可用时由平台提供可重新打开的控制入口，再开放依赖恢复入口的隐藏与穿透操作。

## 定位、焦点与状态

| 场景 | 行为 |
| --- | --- |
| 切换临时面板 | 同一时刻最多一个临时面板展开。右键快捷面板和双击速览可互相切换。通知避让正在操作的区域。 |
| 桌宠移动、吸边或跨屏 | 打开临时面板时暂停自主移动，开始拖拽时收起。按角色当前屏幕和工作区布局，贴边时向内展开，空间不足时采用稳定的备选方位。跨屏或缩放变化时重新约束位置。 |
| 键盘与焦点 | 用户主动打开或进入面板时可用键盘操作，临时面板支持 Esc 和外部点击收起。通知气泡显示时维持原焦点。功能中心与设置中心始终可在失焦后继续使用。 |
| 展开或恢复功能中心 | 首次可在桌宠附近打开，之后按窗口自己保存的位置恢复并约束到可用工作区。展开速览时进入对应客户端详情。窗口默认按系统层级管理。 |
| 隐藏角色或自动全屏隐藏 | 一并收起桌宠附属浮层，独立功能中心与设置保留各自的可见状态。托盘仍能恢复角色。 |
| 关闭功能中心或设置 | 功能中心关闭只改变窗口可见性。后续任务停止通过独立命令执行。设置打开期间可使用其他入口，设置草稿保留到用户应用或取消。退出程序时关闭所有界面。 |
| 快捷修改设置 | 滑条拖动时预览，提交时保存一次。快捷面板、托盘、设置共用已确认值。设置草稿提交时仅应用实际编辑字段，感知其他入口的新值。若同字段发生冲突，明确提示并保留用户可选操作。 |

## 客户端页面与会话

功能中心共享窗口导航、客户端与实例选择、连接状态和刷新反馈。应用按客户端和能力提供页面，适配器提交数据与能力。ChatGPT 桌面客户端首发提供真实信息字段，后续按已验证接口加入会话列表、对话和完整会话流。DeepSeek Harness 桌面版可按自身能力提供工作区、任务或会话视图。字段、文案与操作以各客户端已验证的接口为准。

| 连接状态 | 展示和操作 |
| --- | --- |
| 从未配置 | 显示连接引导并提供设置入口，桌宠便捷操作照常可用。 |
| 正在刷新 | 当前值仍可阅读，显示刷新状态及原有时间戳。 |
| 暂时断开、超时或需认证 | 提供重连或认证入口，保留该实例被允许展示的旧值并标记过期。暂停依赖连接的操作。 |
| 功能或字段不受支持 | 主要入口按实际能力显示，连接详情给出原因。 |
| 换客户端或实例 | 只显示当前实例的快照。后续对话草稿、阅读位置和执行状态各自隔离。 |

完整会话流在独立窗口中显示。长消息、工具调用与文件差异按需展开，用户向上阅读时保留滚动位置并提示新内容。迷你对话属于后续可选视图，和完整窗口共用会话、草稿及阅读状态。断连时保留草稿和已收到的内容，清楚标记未确认的发送状态，重发由用户发起。审批、取消与正文保留策略见[客户端集成](integrations.md)。

## Windows 与 Linux 的面板实现

Windows 的现代化替换范围为面板前端，包括快捷浮层、信息速览、功能中心和设置中心，以及后续引入的通知气泡。角色透明窗口、素材播放、渲染和命中继续沿用现有 Windows 路径。托盘保留平台原生恢复入口。视觉目标为现代 Windows Fluent 风格，跟随系统浅色／深色、文本及控件状态。角色主题可点缀头像、海报和强调色。

优先验证 WinUI 3 与 Rust `windows-reactor` 能否承载 Windows 面板。`windows-reactor` 的上游文档将其列为预览库，并说明安装运行时和自带运行时的部署方式。技术选型在实际验证后确定。用相同面板数据与应用命令作为接入边界，现有 egui 前端可作为过渡实现。验证包括面板线程与桌宠事件循环的协调、关闭与退出、部署和运行成本。[WinUI 3 官方文档](https://learn.microsoft.com/en-us/windows/apps/winui/winui3/) · [windows-reactor 上游文档](https://github.com/microsoft/windows-rs/blob/master/crates/libs/reactor/readme.md)

Linux 允许独立实现面板前端，复用应用命令、客户端数据模型、设置状态与交互规则。各桌面可按平台能力选择不同控件和窗口形态。无法提供可靠的桌宠锚定浮层时，可以用普通窗口呈现相同操作。窗口定位、托盘和恢复入口随目标桌面验收。

## 切片与验收

| 切片 | 检查场景 |
| --- | --- |
| 普通桌宠与设置 | 角色右键和托盘菜单各自显示对应内容。单击、双击、拖拽与吸边按各自规则执行。缩放、自移动和设置保存一致。隐藏与穿透可恢复。 |
| 首发信息查询 | 双击速览可刷新真实字段并展开正确详情。未连接、需认证、断连、未知字段、过期与换实例都有对应视图。关闭功能中心后可从角色或托盘重新打开。 |
| Windows 面板验证 | 用中文输入、长列表、流式追加文本样本检验候选组件。覆盖 Esc、外部点击、焦点恢复、混合 DPI、跨屏、断屏、吸边布局和重复开关。样本与真实对话功能分开验收。 |
| Linux 面板 | 在目标桌面复验可用入口、定位或普通窗口的替代路径、焦点、设置与恢复。 |
| 对话扩展 | 展开或切换紧凑视图后保持会话和草稿。失焦、隐藏角色、关闭窗口、断连与停止任务各自可验证。 |

按[性能方案](performance.md)对照只运行桌宠、打开浮层、打开功能中心或设置及关闭后各状态，记录增量内存、唤醒、首次打开时间与发行体积。候选面板运行时、字体和新增进程一起计算。界面拆分参考了 fork 的[桌宠控制栏](https://github.com/xiamoqingliang/bailong-codex-pet/blob/main/codex-integration/bridge/bailong_toolbar.py)和[窗口行为管理](https://github.com/xiamoqingliang/bailong-codex-pet/blob/main/codex-integration/bridge/window_policy.py)。
