# 面板与窗口交互

2026-11-14 已确认交互方向与平台边界。本文描述目标设计。当前行为见[使用说明](../user/guide.md)，首发范围和待定选项见[实施主线](../plan/roadmap.md)与[取舍清单](../plan/decisions.md)。

## 入口与职责

| 入口 | 打开的界面 | 内容与关闭方式 |
| --- | --- | --- |
| 左键单击角色 | 角色互动 | 沿用点击动作与吸边探头。拖拽、单击和双击互斥。 |
| 右键角色 | 快捷操作栏 | 贴近角色的窄幅圆角纵栏，提供聊天窗口、缩放、动作预览和快捷设置，贴边时增加「展开桌宠」。 |
| 左键双击角色 | 信息速览 | 桌宠旁的临时浮层，按客户端列出自动刷新的摘要卡片，每张卡提供对应的详情入口。 |
| 快捷面板、速览或托盘入口 | 聊天窗口 | 独立可缩放的轻量客户端，提供客户端切换。当前页面用于阅读、发送和接收该客户端会话的消息。连接详情、套餐和刷新放在辅助视图，窗口保留位置。 |
| 托盘右键 | 程序管理菜单 | 保留程序级常用开关、进入设置、恢复与退出。 |
| 托盘菜单或快捷栏内的「快捷设置」→「全部设置」 | 设置中心 | 独立普通窗口。管理外观与行为、素材、客户端连接、自启、通知与诊断。显式应用或取消。 |
| 客户端结果或任务事件 | 通知气泡 | 简短、非激活、自动收起。后续支持从通知打开对应详情。 |

快捷栏的缩放区占一行，从左到右为「+ 缩放 -」，比例在设置中心查看。「动作预览」打开栏内有高度上限的滚动列表，展开后按钮显示「收起动作」。「快捷设置」在同一区域显示自移动、音效、全屏隐藏和「全部设置」。托盘不可用时，此菜单也提供退出。两个子菜单同一时间仅展开一个。

Windows 快捷栏收起子菜单时为 124 × 144 DIP，缩放按钮各宽 34 DIP。贴边时多一行，子菜单展开后按限定高度扩展。动作名允许换行。快捷栏和信息速览均使用 Windows 系统圆角。 [Windows 窗口圆角](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners)

托盘菜单默认保留显示／隐藏角色、关闭鼠标穿透或恢复控制、打开聊天窗口、音效／自移动、设置及退出。关于和诊断可收进设置。托盘菜单和快捷面板共用自移动等应用命令，各自组织入口。托盘不可用时由平台提供可重新打开的控制入口，再开放依赖恢复入口的隐藏与穿透操作。

## 设置面板布局

各平台的设置面板采用紧凑纵向布局，初始尺寸按系统缩放和工作区选定，使用期间固定尺寸。内容纵向滚动，底部保留固定的关闭与应用按钮。

顶部将角色预览和素材主题名称并排垂直居中。普通设置、客户端集成、素材和维护各自分组，以分隔线和留白区分。任务气泡开关下连续放置「缩放比例」和「气泡大小」滑条，每项的名称与百分比分居行左右。音效与试听随行宽布局。目录选择、检查和定位归入素材区，恢复默认和退出归入维护区。素材区提示异常和回退，检查与保存操作提供结果反馈。

Windows 设置窗口默认客户区为 300 × 500 DIP（宽 × 高，比例 3∶5），首次打开受当前屏幕工作区约束，禁止拖边调整与最大化。Windows 面板标题直接使用各自名称。设置和聊天窗口使用系统 Mica 材质，快捷面板和速览使用系统 Acrylic 材质，由系统处理主题与透明效果。 [Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica) · [Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)

客户端连接由设置面板的复选框管理。「连接到ChatGPT」默认勾选，应用设置后生效。发现和连接恢复由桌宠自动处理。 [连接设置](integrations.md#连接设置与来源选择)

## 信息速览

同一个浮层列出所有已启用客户端的卡片，包括等待连接、需认证或暂不可用的客户端。卡片首行显示连接状态，套餐和客户端版本同排。各额度窗口用进度条显示剩余比例，右侧显示剩余百分比和本地重置时间。刷新中、错误和过期状态逐卡呈现。没有启用客户端时提供设置入口。卡片超出浮层可用高度时可滚动，浮层仍受当前工作区约束。

## 定位、焦点与状态

| 场景 | 行为 |
| --- | --- |
| 切换临时面板 | 同一时刻最多一个临时面板展开。右键快捷面板和双击速览可互相切换。通知避让正在操作的区域。 |
| 桌宠移动、吸边或跨屏 | 拖动或自主移动时，两个浮层都带惯性跟随角色。角色停下后，浮层减速到锚点。贴边时优先向工作区内展开，缩放或内容高度变化时重新约束位置。跨屏或 DPI 变化时直接按新工作区定位。 |
| 键盘与焦点 | 拖动角色、点击空白桌面或普通点击浮层内时保留浮层。切到其它应用窗口或在浮层内右键时收起。再次右键角色关闭快捷栏，再次双击角色或在速览内按 Esc 关闭速览。聊天窗口与设置中心可在失焦后继续使用。 |
| 展开或恢复聊天窗口 | 首次可在桌宠附近打开，之后按窗口保存的位置恢复并约束到可用工作区。从快捷面板或托盘进入时恢复上次查看的客户端及其会话视图。展开速览卡片时直达该卡片对应客户端的连接详情。窗口默认按系统层级管理。 |
| 隐藏角色或自动全屏隐藏 | 一并收起桌宠附属浮层，独立聊天窗口与设置保留各自的可见状态。托盘仍能恢复角色。 |
| 关闭聊天窗口或设置 | 聊天窗口关闭只改变窗口可见性。后续任务停止通过独立命令执行。设置打开期间可使用其他入口，设置草稿保留到用户应用或取消。退出程序时关闭所有界面。 |
| 快捷修改设置 | 滑条拖动时预览，提交时保存一次。快捷面板、托盘、设置共用已确认值。设置草稿提交时仅应用实际编辑字段，感知其他入口的新值。若同字段发生冲突，明确提示并保留用户可选操作。 |

## 聊天窗口与会话

一个聊天窗口提供客户端切换，每次显示一个客户端的页面。各客户端共享窗口和导航，页面的布局及操作按各适配器已验证的能力呈现。会话页面为会话选择、消息阅读和输入保留主要空间。M2 已实现的套餐和来源诊断随对话布局迁入连接详情。

| 区域 | 内容与交互 |
| --- | --- |
| 会话栏 | 提供客户端切换，显示当前客户端、已绑定会话和连接状态。支持选择会话、回到客户端以及打开连接详情，入口随能力显示。 |
| 消息区 | 展示同一客户端会话的已收消息和流式回复。按需加载较早消息，工具输出和文件差异在确有支持后按需展开。用户向上阅读时保持原位，提示有新消息。 |
| 输入区 | 输入框与发送状态固定在底部。模式、模型与推理强度在适配器支持时作为输入区的轻量选择项。上下文统计可在此显示简要状态，详细含义可展开。 |
| 连接详情 | 容纳来源、套餐、Codex 额度及重置时间、更新时间、手动刷新和清除缓存。只读或需认证时可进入详情和设置，发送入口按当前能力禁用。 |

独立窗口默认把空间留给消息和输入。宽度不足时把次要控件收进菜单或抽屉，完整会话列表也可按需展开。具体对话布局在验证连接及同会话能力后按客户端实施，届时补测窄窗、长消息、输入焦点和状态反馈。当前窗口显示 M2 的只读查询。

| 连接状态 | 展示和操作 |
| --- | --- |
| 连接已关闭或等待客户端 | 关闭时提供设置入口；启用后自动查找桌面客户端。 |
| 同一客户端发现多个独立来源 | 在该客户端的连接详情中选择。取消后保留入口，其余客户端照常使用。 |
| 正在刷新 | 当前值仍可阅读，显示刷新状态及原有时间戳。 |
| 暂时断开、超时或需认证 | 提供重连或认证入口，保留该实例被允许展示的旧值并标记过期。暂停依赖连接的操作。 |
| 功能或字段不受支持 | 主要入口按实际能力显示，连接详情给出原因。 |
| 切换客户端页面 | 恢复目标客户端的快照和会话视图。原客户端连接继续工作，在途回复仍归属原会话。 |
| 切换来源、账号或会话 | 显示目标来源和会话的数据。草稿、阅读位置、运行中的消息及请求状态按来源、账号和会话保存。 |

快捷面板与信息速览将常用操作和会话入口引向聊天窗口。后续如加入迷你对话或内嵌输入，复用同一会话、草稿和发送状态。断连时保留当前草稿和已收到的内容，未确认的发送状态明确可见，重发由用户发起。 [会话能力与数据边界](integrations.md#对话的后续边界)

## Windows 与 Linux 的面板实现

Windows 的现代化替换范围为面板前端，包括快捷浮层、信息速览、聊天窗口和设置中心，以及后续引入的通知气泡。角色透明窗口、素材播放、渲染和命中继续沿用现有 Windows 路径。托盘保留平台原生恢复入口。视觉目标为现代 Windows Fluent 风格，跟随系统浅色／深色、文本及控件状态。角色主题可点缀头像、海报和强调色。

Windows 采用 WinUI 3 与 Rust `windows-reactor`，依赖对应架构的 Windows App Runtime 2（至少 2.4）。设置、快捷面板、速览和聊天窗口由独立、按需启动的子进程运行 Reactor。快捷面板与速览先由 DWM 隐藏，待原生工具窗口样式、角色锚点和控件布局准备好后再显示。桌宠通过匿名管道交换快照与命令，并负责预览、保存、撤销与回收进程。M2 的聊天窗口保留本次桌宠运行中的位置和已选客户端，速览卡片可直达对应只读详情。两个窗口共享各客户端的查询状态。 [WinUI 3 官方文档](https://learn.microsoft.com/en-us/windows/apps/winui/winui3/) · [本机验证](../plan/validation.md#m2-windows-连接与来源隔离)

Linux 允许独立实现面板前端，复用应用命令、客户端数据模型、设置状态与交互规则。各桌面可按平台能力选择不同控件和窗口形态。无法提供可靠的桌宠锚定浮层时，可以用普通窗口呈现相同操作。窗口定位、托盘和恢复入口随目标桌面验收。

## 切片与验收

| 切片 | 检查场景 |
| --- | --- |
| 普通桌宠与设置 | 验证快捷栏首显、跟随、空白点击、再次右键、失焦、子菜单滚动和吸边展开。缩放、偏好开关和设置保存一致，隐藏与穿透可恢复。 |
| 首发信息查询 | 双击速览可刷新真实 ChatGPT 字段并展开正确详情。未连接、需认证、断连、未知字段、过期与换实例都有对应视图。关闭聊天窗口后可从角色或托盘重新打开。 |
| 双客户端速览与切换 | M2 用真实 ChatGPT 和第二个合成来源验证卡片并列、详情直达、切页及单来源故障隔离。M5 用两个真实客户端复验。 |
| Windows 面板验证 | 验证首次可见的位置和圆角、Esc、空白桌面点击、其它应用切换、吸边布局和重复开关。两个浮层均验证拖拽保留、松手后的惯性收敛和跨屏定位。IME、长列表与流式追加在真实对话接入时验证。 |
| Linux 面板 | 在目标桌面复验可用入口、定位或普通窗口的替代路径、焦点、设置与恢复。 |
| 客户端对话 | 在桌宠绑定并继续一条客户端可见会话，确认两端显示同一会话及新增消息。验证流式回复、IME、断连后的草稿与发送状态、会话切换和关闭重开。出现多个客户端页面时，验证切页后草稿恢复、在途回复及发送目标的归属。模式、模型和统计按支持范围验收。 |

按[性能方案](performance.md)对照只运行桌宠、打开浮层、打开聊天窗口或设置及关闭后各状态，记录增量内存、唤醒、首次打开时间与发行体积。候选面板运行时、字体和新增进程一起计算。参考 fork 将聊天、同会话同步与历史集中在聊天入口，并收起较长的工具详情。本项目将同会话阅读和输入放在聊天窗口的主窗口。 [参考 fork 的使用路径](https://github.com/xiamoqingliang/bailong-codex-pet/blob/534f9b9b32622c6e4e504ac389eda81a75458821/README.md#同一条-codex-聊天与历史同步)
