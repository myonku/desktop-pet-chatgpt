# 素材协议与制备设计

状态：开发和首发统一使用 v2 PNG，现行字段和限制见 [v2 运行时契约](../development/runtime-v2.md)。

## 三类资源分开管理

| 类别 | 用途 | 是否随默认安装分发 |
| --- | --- | --- |
| 原始素材 / 画质参照 | 不可变原件、解码参考、裁切/去噪对比、720 全尺寸候选 | 否；原始母版与经 contour 修改的参照必须分开命名 |
| 默认运行包 | 320 px PNG v2 十动作候选，覆盖普通桌宠行为 | 首发默认使用十动作范围，公开素材来源待确认 |
| 完整开发包 / 高清对照 | 39 动作语义、预览和调度回归，或更高分辨率画质对照 | 独立开发使用，体积和运行证据单列 |

全套动作是资源库的完整性目标，不是默认产品必须装入的内容。派生动作按是否有独特视觉价值选择离线生成、共享帧变换或行为回退；不得为了满足十个固定动作名机械地产生十份动画。

## 素材数据模型与扩展方向

| 对象 | 拟定字段 / 约束 | 设计理由 |
| --- | --- | --- |
| 身份 | schema_version、pack_id、pack_version、display_name、作者/来源 | 稳定 ID 与显示名称分离；包版本不再追随应用版本 |
| 兼容 | engine_api、required_features、可选最小 app 版本 | 优先依据能力契约判断；未知必需能力拒绝，未知可选能力降级 |
| 内容 | clips、images、audio、texts；每载荷相对路径、字节数、SHA-256 | 引用去重；体积与解码成本可预检 |
| 语义绑定 | 固定语义 → 包内变体字典与默认变体 | 引擎定义行为，素材包决定表现。保留现有 clip ID |
| 几何 | 逻辑画布、锚点、裁切矩形、偏移、播放时序、可选移动时窗 | 分辨率不改变角色占屏大小；裁切不改变锚点 |
| 质量档 | 同一语义内容的候选分辨率/编码、完整性标记 | 安装和解码只选一档，避免把所有 PNG/RGBA/BC7 一起打包 |
| 补充元数据 | 来源台账引用、制备配方哈希、预览图、许可声明 | 来源可追溯；运行不必加载逐帧制备记录 |

建议初版仍为只读目录包；ZIP 仅是运输格式。导入先解到临时目录、校验，再原子发布到用户包目录，运行过程中不原地改写。压缩包导入尚未实现：需要总解压大小、文件数量、单文件、路径穿越、符号链接/重解析点和压缩炸弹限制。哈希是完整性检查，不是作者真实性证明。

### 最小能力与回退

| 绑定 | 要求 | 缺失时 |
| --- | --- | --- |
| idle | 必需，至少一个可循环 clip | 拒绝包，继续使用已确认包 |
| interact / drag / land | 可选 | 当前/基础姿态，不凭空触发移动 |
| move.left / move.right | 对应方向与移动时窗必须合法 | 禁用缺失方向的自动移动；不擅自镜像 |
| move.up-left / move.up-right / move.down-left / move.down-right | 可选，沿用对应的左右朝向及合法移动时窗 | 复用同向明确绑定的 `fly`。缺少可用飞行动作时走水平路线 |
| dock / peek | 可选，支持共用 clip + 不同变换 | 按平台能力使用基础停靠姿态或关闭特有姿态 |
| 名称/海报/音效 | 可选 | 通用名称/无海报/静音 |

素材包可以装饰角色与客户端展示，但不能修改错误语义、权限请求、数据来源或程序身份。建议将应用图标保持为程序身份、角色图标用于角色窗口/托盘主题；是否保留现有应用图标覆盖由 D12 决定。跨平台图标源建议为通用 PNG，ICO 在 Windows 构建/装配时派生。

### 编码与尺寸

首发默认候选使用 v2 的 PNG 单编码模式。后续若开放 GPU 压缩，需要能力探测与可安装的兼容档。

本机 175% DPI 验证后保留 320 px 默认档，480 px 用于大窗口画质对照，720 px 保留画质参照。初版按安装或启动选固定质量档，动态 LOD 后置。 [画质验证](../plan/validation.md#m1-高-dpi-与设置成本验证)

离线页数按展开字节和纹理最大边长计算，不能为所有尺寸固定同一个 batch。循环动作末页与首尾切换、跨页预取要进入验收。需要紧边裁切时保留一致的逻辑画布与锚点；纯透明 RGB 清零、同帧/同页去重优先于复杂有损编码。

## 制备流水线与停止条件

1. 登记原件来源、哈希和允许用途。原件只读；去噪结果不能覆盖“原始”目录。
2. 写交付内容表：源动作、语义绑定/仅预览/不分发、帧数/时长、分辨率、派生父项、理由。
3. 仅处理待机、粒子/特效互动、30 fps 移动和一组吸边姿态；固定同源帧和时间线比较配方。
4. 在黑/白/彩色背景逐帧及整段检查轮廓、细线、特效误删、闪烁和循环；记录保护区。不以自动图像指标取代视觉判断。
5. 样本通过质量和成本门槛后才装配默认包。全量扩展包单独评估，不阻塞真实客户端查询开发。
6. 校验已声明全部载荷，试播全部实际分发动作，生成文件清单、哈希、来源摘要和安装报告。

每轮只改变一个主要因素。探索最多两组候选后必须形成选择或明确延期，不能无限追加 contour/超分/姿态版本。素材优化工具保留为开发工具，用户运行时不安装 Python、模型或 FFmpeg；若将来采用运行时视频，须单独审定解码依赖、寻帧/切换和平台成本。

## v2 PNG 实现

首发默认包使用 `schema_version = 2`。先交付 PNG 单编码目录包、显式语义绑定和引擎兼容声明。当前引擎支持 PNG。BC7/RGBA8 独立档和质量档选择按后续实测开放。

下表列出首发核心约束。色彩、来源及可选资源要求见运行时契约。

| 字段 | 首发约束 |
| --- | --- |
| `schema_version`, `pack_id`, `pack_version` | `schema_version` 固定为 2；包 ID 非空；包版本独立使用 SemVer |
| `engine_api`, `required_features` | 引擎契约为整数 `2`。当前能力列表为空，未知引擎版本或未知必需能力拒绝加载 |
| `encoding`, `pages[]` | 初版 `encoding` 为 `png`。每页有 `id`、`size` 和唯一 `payload`，载荷声明 `path`、`sha256`、`bytes`。校验声明长度、文件内容及运行解码预算 |
| `clips[]` | 声明几何、方向、移动时窗与微秒时间线。`id` 是包内资源 ID，`preview_name` 是可选的短显示名 |
| `bindings` | 每个语义组以 `variants` 映射变体名和 clip ID，再用 `default` 选择组内默认。基础 `idle` 默认须循环。 [完整语义表与示例](../development/runtime-v2.md#引擎行为语义) |

多个语义组可以引用同一个 clip。程序按语义选默认、随机或请求指定变体，变体名称由素材包定义。预览直接播放所选 clip。同侧吸边和探头保留各自画布偏移，允许共用同一组帧页。

动作预览列表中的名称建议控制在约 6 个汉字或 12 个半角字符以内，便于在窄栏中单行显示。

| 实施项 | 交付与验收 |
| --- | --- |
| 清单与运行时 | 直接解析 v2，验证引擎契约与必需能力，按语义绑定解析行为，按 clip ID 预览 |
| 离线制备 | 从原始素材清单与透明 WebM 直接生成 v2 PNG。默认包生成六个基础 clip 和四个派生姿态，全动作开发包另行制备。输出包含来源和配方记录 |
| 校验与装配 | 让 `validate-pack --distribution` 与装配器识别 v2。检查必需能力、循环 `idle`、绑定引用、载荷完整性及现有页预算。缺失可选绑定应按约定降级，未知协议或必需能力给出明确错误 |
| 首次启动与换包 | 以正式 v2 默认包和另一份已制备的 v2 包验证首启、语义绑定、左右吸边与探头、换包和配置失败回退。语义绑定的边界输入由解析器测试覆盖 |

素材 schema 独立于应用版本和 TOML 配置 schema。开发迭代规则见 [D19](../plan/decisions.md)。
