# 客户端信息集成

状态：设计提案，尚无真实适配器。维护者确认的目标是 ChatGPT 桌面客户端和面向国内用户的 DeepSeek Harness（DSH）桌面版。首个集成交付基础信息查询，对话后置。

## 产品与接口证据不能混同

ChatGPT、Codex、OpenAI API 是不同接入对象。现有工程没有证明它们共享账户、额度、任务源或会话协议。不能把本开发助手拥有的连接工具当成独立桌宠可调用的 API，也不能把读取 Codex 状态标记为完成 ChatGPT 集成。

DSH 已明确为桌面版，具体仓库、版本、部署方式和用户实际安装实例待核实。实施前由维护者选定实例，或从可确认的桌面安装及官方项目定位，再确定接入方式、权限与数据格式。

首个技术切片应给出下表中的真实证据。只找到客户端进程或版本，可以完成“安装检测”，不能单独验收“基础业务信息查询”。

| 字段候选 | 首发级别 | 必须验证的语义 |
| --- | --- | --- |
| 客户端身份、版本、运行/连接状态 | 基础诊断 | 安装不等于运行；运行不等于认证；实例不能仅靠进程名唯一标识 |
| 账户/套餐或客户端公开摘要 | 业务字段候选 | 是否可读、是否敏感、是否对应当前实例；不额外抓取不需要的信息 |
| 额度/用量/重置时间 | 业务字段候选 | 单位、分母、窗口、适用模型、时间与时区；不同产品的额度不可互相替代 |
| 当前任务/会话状态摘要 | 业务字段候选 | 是否确有可靠来源、快照还是事件、任务终态的定义；不默认读取正文 |

**首发验收建议**：诊断字段 + 至少一个维护者认可且真实可读的业务字段 + 手动刷新 + 不可用/过期展示。字段清单在接入调查结束时冻结。若没有可靠业务字段，明确记录目标受阻及替代选项，由维护者选择延后集成或改首发范围；不能静默用假数据、进程检测或 Codex 替代。

## 来源选择与能力矩阵

优先使用可验证的公开接口或客户端明确支持的本地接口。只读文件/数据库适配仅作为需要维护版本兼容的候选；不预设“只读就是稳定 API”。是否接受未公开接口和版本跟随成本由 D04 决定。UI 自动抓取不作为默认生产架构。

每个字段的接入记录包含：客户端产品/版本/平台、传输方式、来源文档或代码/实际样本、必要权限、原始语义、归一化规则、刷新成本、失败模式、测试版本范围。记录脱敏样本，不保存真实 token 或完整会话。

| 适配器 | 现状 | 首发 / 后续 |
| --- | --- | --- |
| ChatGPT 桌面客户端 | 未验证接口、未实现 | 首发主线，先真实只读字段闭环 |
| DeepSeek Harness 桌面版 | 产品形态已确认，具体版本和接入方式待核对 | 第二适配器，按平台分别核实支持范围 |
| 合成适配器 | 拟新增 | 验证超时、隔离、未知字段和过期；永远不能替代真实接入验收 |

## 查询契约草案

```text
ProviderIdentity = product_id + adapter_id + instance_id + client_version
Capabilities = set of queryable semantic field IDs
Probe -> identity, connection_state, capabilities, unsupported_reason
Refresh(request_id, connection_epoch, selected_fields) -> Snapshot | Error
Snapshot = provider_identity, epoch, request_id, observed_at, expires_at, fields
Field = key, typed_value, unit?, scope?, source, source_time?, availability
availability = available | unavailable(reason) | unknown | stale
```

连接状态区分 Disabled、Probing、Ready、NeedsAuth、Unsupported、Unavailable。Ready 不表示所有字段都可查询；每个字段独立降级。时间内部使用 UTC，界面显示用户本地时间/明确时区；来源不提供采样时间时标记本地获取时间，不伪造服务端时间。

缓存键包含实例和字段作用域，不能仅用显示名称；换账户、换实例、重连时增加 epoch。只接受当前 epoch 的响应，不把旧额度刷新到新账户。空值、0、无限额、未知和过期分别显示。

建议单次查询超时 5 秒，单客户端最多一个刷新请求，重复点击合并。默认手动刷新；如选择后台查询，初始间隔不短于 60 秒，隐藏可降低频率，失败指数退避上限 15 分钟。这些是待实施初值，实际接口限制优先；认证失败和未知版本停止自动重试，需用户处理。退出取消自有查询，不关闭用户客户端。

## 界面与隐私

首发提供信息速览和功能中心中的客户端详情。两处共享选中实例、连接状态和查询快照。速览面向短时检查，详情容纳字段来源、时效、刷新与能力说明。查询期间保留旧值并标记刷新中，失败后标记过期或错误。面板关闭后是否继续定时刷新以设置为准。具体交互见[面板与窗口交互](panels.md)。

连接默认关闭。用户启用时说明读取范围与来源；账户标识默认脱敏。优先引用现有客户端授权机制，不将凭据写进素材包、普通配置、日志或诊断导出。日志只记录字段状态、耗时、错误类别与匿名关联 ID。清除缓存与停用连接应有明确入口。

## 对话的后续边界

查询能力不推导出发送能力。后续另定义 SendMessage、Cancel、Approval 等独立能力和权限；会话归属、正文保存、草稿、流式内容、IME、断线恢复、请求幂等、取消确认和审批绑定一起验收。任务观察也单独定义事件水位和去重。首发不为这些预建完整数据库或执行器，只保留稳定的 provider/instance 身份和窄消息边界。
