# 总体设计与推进计划

本文维护产品范围、总体设计和风险。主线关口见 [G-04](G-04-delivery-plan.md)。

## 1. 设计取向

优先验证透明窗口和有界媒体管线，再扩展完整桌宠行为与外部集成。行为、模块契约和验收分别在 [功能规格](G-02-feature-spec.md)、[架构](G-03-architecture.md) 和 [验证矩阵](G-06-validation.md) 维护。

Rust 的学习与维护价值是选型依据。性能结论按统一条件实测。

## 2. 产品范围

首发 Windows x64，Windows 11 优先验收；Windows 10 待依赖与设备验证。单角色、单桌宠实例、本地使用、可离线运行基础桌宠功能。桌面版 ChatGPT 为首个产品集成目标，既有 Codex 会话和任务机制为待验证的技术接入线索，二者不等同于已验证的统一接口。DeepSeek Harness（DSH）后续独立排期。

| 层次 | 本期交付 | 不纳入本期 |
| --- | --- | --- |
| 基础桌宠 | 动作、拖拽、自移动、吸边、缩放、托盘、隐藏、音效、偏好 | 多角色同时运行、素材市场、编辑器 |
| 辅助界面 | 设置、气泡、会话输入、历史与状态 | WebView、复杂富文本执行、插件运行环境 |
| 可选集成 | 能力探测、任务提醒、额度、会话与审批/取消 | 绕过客户端权限、任意私有 schema 兼容承诺 |
| 工程 | 有界资源、本仓库历史版本的数据迁移、诊断、可追溯 Windows ZIP | 安装器、自动升级、跨仓库长期存储兼容、跨设备同步、Linux/macOS/ARM64 |

基础桌宠 P2 可独立验收；包含集成的候选版本须完成 P3。首版不因集成不可用而阻止普通桌宠启动，但不能把缺失的 P3 标为已交付。

## 3. 已定与待证实

已定：Rust stable/MSVC、winit、wgpu/WGSL、Windows 平台封装、egui 辅助 UI；标准线程和有界消息；默认用户包不依赖 Python/Qt，目标不需要运行时 FFmpeg。单 Cargo 包起步，按模块分工，出现独立发布需求后再拆 workspace。

透明窗口采用 D3D12/DirectComposition，锁定依赖由 Cargo.lock 记录。运行时从解包目录读取素材，透明 PNG 为默认兼容档。素材包契约见 [G-05](G-05-contracts.md)，性能预算见 [G-06](G-06-validation.md)。

整套素材包可替换，客户端专属展示资源通过适配器身份选择。首次尺寸与配置覆盖规则见 [G-02](G-02-feature-spec.md) 和 [G-05](G-05-contracts.md)。

按 [G-04](G-04-delivery-plan.md) 的关口依赖推进，执行状态与证据进入对应阶段文档。

## 4. 风险与处置

| 风险 | 触发条件 | 处置与决策节点 |
| --- | --- | --- |
| 透明窗口不成立 | 黑底、焦点错误或恢复失败 | P1a 停止扩展功能，记录复现；限一个原型迭代调查平台呈现后备，仍不通过则复核后续依赖与范围 |
| BC7 画质或包体不合适 | 边缘可见损伤、无稳定收益或超预算 | P1b 选择 PNG/RGBA 有界路径；不自动回到运行时视频解码 |
| 全量素材规模未知 | 代表动作装配接近原型包体预算，或完整动作需要不同分页/时序策略 | P2 记录拟交付动作覆盖率、转换输入和体积估算，P4 对实际附件确定范围与预算。P1b 的 80 MiB 依据为三段代表动作的本地装配 |
| 私有集成变更 | 未知协议/schema、客户端缺失 | 仅禁用对应能力，保留普通桌宠；P3 明确支持版本 |
| 范围膨胀 | 原型被要求同时做素材编辑/多平台 | 放入后续候选，不侵入 P0–P4 |
| 素材与代码许可未明 | 无可追溯分发依据 | 自有测试资源继续开发；相关公开包阻塞，不据此阻塞所有原型 |
| 缺少测试设备 | 私人笔记本只有内屏，或未取得指定 GPU/DPI 环境 | 两套笔记本分别完成可运行的单屏回归。扩展桌面和混合 DPI 按独立专项记录，候选版按实测范围声明支持。[设备排期](G-04-delivery-plan.md#设备排期) |

## 5. 工程与分发约束

首期采用便携程序 ZIP，配置写用户数据目录。素材包作为独立 ZIP 附件分发；源码、程序和素材各有装配清单。资源本体和装配产物留本地，素材契约与小型合成样本随源码维护。附件布局和装配方式见 [G-05](G-05-contracts.md)。

根 README 保留当前许可声明。代码、角色/动画、音效、字体、依赖和转换器分别登记来源、哈希、许可证据与允许用途，台账字段见 [G-05](G-05-contracts.md#素材工作区)。
