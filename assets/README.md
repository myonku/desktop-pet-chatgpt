# 本地素材工作区

- `source/white-dragon/` 存放当前角色的原始动画、音效、素材清单和来源及许可说明。转换时从这里选择输入。
- `packs/<pack-id>/<pack-version>/` 存放转换后的解包素材包，包根直接包含 `manifest.json`。

素材本体留在本地。新克隆可按项目首页生成合成包并设置 `pack_path`。当前包根、必备文件和格式遵循本项目的版本化素材协议，后续可随开发调整。本项目独立维护协议与转换方式，无需跟随上游仓库发行附件的目录和命名。见 [素材包 v1](../docs/G-05-contracts.md#素材包-v1)和[素材工作区](../docs/G-05-contracts.md#素材工作区)。
